## Perubahan setelah melihat data

| Tanggal | Ambang | Dari | Ke | Alasan (wajib, dengan angka) |
|---|---|---|---|---|
| 2026-11-12 | Cakupan aktor Apify (`max_posts_per_player`, `timeFilter`, `sort`) | 5 post, `timeFilter: all` | 15 post, `timeFilter: year`, `sort: top` | Diukur pada pilot: hanya 35% item yang dikembalikan jatuh di dalam musim (207/585); `timeFilter: all` mengembalikan saga transfer Jun-Okt 2026 yang seluruhnya gugur. Dengan 15 post: 8/15 post dan 81 komentar in-season, tetapi hanya ~13 komentar per pemain yang menyebut pemain itu. Artinya hampir semua pemain akan berlabel `bukti terbatas` (10-29), bukan `bukti cukup` (>=30). Biaya terukur: $0.155/pemain, 70 pemain = $10.87 - melebihi sisa kredit Apify, jadi jalur ini hanya sanggup ~20 pemain. |
| 2026-11-12 | Biaya pilot Apify (dihentikan) | $0.8717 terpakai dari kredit gratis $5 | Dihabiskan untuk 6 run pilot + 1 run 25 pemain yang dihentikan di 4/25. Sisa kredit $4.128 tidak dipakai. Bukti mentah tiap run ada di `data/raw/reddit/` dan run yang terhenti tidak menghasilkan file interim. | B |
| 2026-11-12 | Privasi penulis komentar (aturan 11) | Field `author`/`authorId`/`authorFlair` dibuang sebelum payload ditulis ke disk | Pelanggaran ditemukan saat audit: 502 username tersimpan di 1.078 item `*.items.json`. 14 file sudah disanitasi (0 username tersisa); `scrub_identity()` sekarang dijalankan sebelum penulisan, sementara deteksi bot tetap berjalan lebih dulu karena butuh nama. File mentah tidak pernah masuk git, jadi tidak ada username di riwayat repo | B |
| 2026-11-12 | Sanitasi payload Arctic Shift: blacklist → **whitelist** | Hanya `id`, `body`, `created_utc`, `subreddit`, `score`, `permalink`, `link_id`, `stickied`, `_skip` yang disimpan | Pilot pertama membuktikan blacklist gagal: objek komentar Reddit berisi ~72 field, dan `profile_img` (URL avatar penulis) serta `link_author` (username penulis post) lolos ke `*.comments.json` dan ke cache. Whitelist dipakai karena daftar field arsip bisa bertambah kapan saja. Cache dan file mentah sudah disanitasi ulang; audit 20 file pilot20: hanya 9 kunci di atas yang tersisa | B |
| 2026-11-12 | Jendela tanggal Arctic Shift | Halaman pertama dibatasi `before=<akhir musim>`, dan `after`/`before` dikirim sebagai **epoch int** | Bug yang terbukti: halaman pertama hanya dikirim `after=<awal musim>` tanpa batas atas, sehingga `sort=desc` mulai dari baris terbaru arsip — untuk `pickford` hasilnya baris Okt 2026, semuanya gugur di filter jendela musim, dan pemain itu pulang dengan **0 komentar**. Setelah `before` ditambahkan: 89 komentar. Konversi ke epoch int murni kehati-hatian (probe ISO sempat 422, tetapi 422 di arsip ini juga berarti beban server, jadi itu **bukan** bukti bahwa ISO ditolak; format yang benar-benar terverifikasi jalan adalah epoch) | B |
| 2026-11-12 | Batas teks per pemain ditegakkan di mapper | `quota=max_texts_per_player - kept` diteruskan ke `records_from_comments` | Pilot `--pilot 3` menyimpan 89 dan 93 komentar padahal kuota 60: mapper dipanggil dengan `quota=None` sehingga satu halaman penuh menembus batas. Setelah perbaikan pilot yang sama menghasilkan 33/60/60 | B |
| 2026-11-12 | Sampling review relevansi: hash+round-robin → **acak ber-seed** | `random.Random(text_sample.random_seed).sample(...)` | PRD §11 dan AGENTS.md meminta 100 teks **acak**; pemilih lama deterministik tetapi bukan acak (round-robin antar pemain melebihkan pemain dengan teks sedikit). Seed dari config (aturan 13) supaya bisa dibuat ulang. `score_review()` sekarang menolak menyatakan `LULUS` bila label < 100 | B |
| 2026-11-12 | Retry Arctic Shift | Backoff exponential 10/20/40 s, tangga limit `[100, 25]` sekali jalan, reset 429 dipatuhi, dan 403/401 menghentikan run | AGENTS.md mewajibkan exponential backoff, bukan jeda tetap. Satu tangga penuh sudah 8 percobaan; putaran kedua sempat dicoba dan **dibatalkan**: probe `alisson` gagal 16/16 dalam 464 detik tanpa komentar tambahan, jadi retry lebih banyak hanya menggandakan beban tanpa bukti manfaat. Kegagalan 422 dicatat sebagai `failed_requests`, bukan diakali. Reset `X-RateLimit-Reset` hanya diberlakukan pada 429 (kontrak README); 422/5xx cukup backoff. Header reset juga muncul pada 200/422, jadi keberadaannya bukan bukti rate limit | B |
| 2026-11-12 | Temuan: recall hilang pada marga majemuk (`Jacob Bruun Larsen`, `Jørgen Strand Larsen`) | tidak diperbaiki di Tahap B; dilaporkan sebagai temuan + keterbatasan | `split_name()` di `src/population/identity.py` menganggap token terakhir sebagai marga, jadi `Larsen` dihasilkan tetapi `Bruun Larsen`/`Strand Larsen` **tidak pernah** dibuat. Karena ada dua pemain bermarga `Larsen` di sampel, `drop_colliding_aliases()` (`src/population/build.py`) membuang `Larsen` dari keduanya (kanonik bukan "Larsen"), sehingga alias yang tersisa hanya nama lengkap + bentuk inisial. Dampak terukur di pilot20: `fotmob_655575` menarik 5 komentar mentah, **3** di antaranya menulis "Bruun Larsen", tetapi mapper tidak menemukan alias mana pun → 0 komentar disimpan. Sampel terkunci tidak boleh disunting (aturan 14), dan memperluas `AliasIndex` dengan token terakhir secara global akan mengaitkan `Gomes`/`Silva` ke pemain yang salah, jadi perbaikan ini ditinggalkan untuk populasi berikutnya. Catat di keterbatasan laporan | B |
| 2026-11-12 | `Alisson Becker` 0 komentar: **bukan** masalah alias | dicatat sebagai `failed_requests`, bukan bug kode | Alias `Becker` tersedia untuk pemain itu. Audit cache: tidak ada satu pun halaman `r/LiverpoolFC` dengan `body=becker` yang berhasil; seluruh 8 percobaan (4 percobaan x 2 limit) dibalas 422 dan ditandai `failed_requests: 1` pada `summary.json`. Ini kegagalan request, bukan retrieval kosong, dan dibiarkan gagal daripada menambah putaran retry | B |
